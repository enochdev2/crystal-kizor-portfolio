I approached the brief as a brand-architecture and business-routing problem rather than simply placing seven initiatives on one page. Crystal is the umbrella brand, with architecture at the centre: selected work and Studio COKA receive the strongest visual emphasis, while product design, education, research, speaking and impact initiatives are grouped into clearer Build, Learn & Share, and Impact paths.

I used Next.js and TypeScript because the brief values speed, discoverability and technical quality. The experience is static-first and uses responsive Next.js images, semantic HTML, structured metadata, a dedicated social preview, accessible mobile navigation and limited client-side JavaScript. Key ecosystem content and routing data are separated from presentation so links and future content changes can be made without restructuring the page.

Business impact is treated as product functionality. Visitors can submit a validated, intent-based enquiry through a server route, while Studio COKA has a verified direct destination. Vercel Web Analytics records traffic and conversion events, while Speed Insights and Web Vitals reporting measure real-user performance. This allows post-launch improvements to be based on the enquiry funnel rather than page views alone.
