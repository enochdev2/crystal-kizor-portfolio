# Crystal Kizor — Stage 1 Web Developer Assessment

A personal-brand landing page for Crystal Kizor, bringing her work across architecture, design, education, research, speaking and social impact into one clear experience.

Built with Next.js 16, React 19, TypeScript and Tailwind CSS v4.

## Links

- **Live website:** https://crystal-kizor-portfolioo.vercel.app/
- **Source code:** https://github.com/enochdev2/crystal-kizor-portfolio

## Approach

The page treats Crystal Kizor as the umbrella brand, with architecture at the centre.

Selected work and Studio COKA receive the strongest visual emphasis, while the wider ecosystem is grouped into three clearer paths:

- **Build**
- **Learn & Share**
- **Impact**

The goal is to help first-time visitors quickly understand who Crystal is, what she does, what she is building and where to go next.
